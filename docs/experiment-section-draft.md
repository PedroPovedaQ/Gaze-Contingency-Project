# Experiment

## Task

For this experiment, a mixed reality conjunction-search task was implemented in which participants searched a virtual bookshelf for a target object while wearing a video see-through headset. The virtual bookshelves were spatially registered to a real table in front of the participant, allowing the participant to see the physical room through passthrough while interacting with virtual objects arranged on the table surface. The participant's goal in each round was to find one target object specified by a conjunction of color and shape. For example, a round might require the participant to find the purple capsule or the red sphere.

The object array contained 56 virtual objects distributed across two seven-row bookshelf columns. Each object was defined by one of six shapes and one of four colors. The shape set consisted of sphere, cube, pyramid, cylinder, star, and capsule, and the color set consisted of red, blue, yellow, and purple. Each round contained one target, 13 distractors that shared the target color, 13 distractors that shared the target shape, and 29 neutral distractors that shared neither target feature. This distribution was selected to require conjunction search; participants could not reliably solve a round by searching for only the target color or only the target shape.

Participants selected objects using eye gaze. When the participant looked at a virtual object, the object received an orange edge highlight. If the participant maintained gaze on the same object for 1.6 seconds, the object was captured. During the dwell interval, the object's highlight progressively increased in intensity, providing continuous visual feedback that the system was charging a selection. When the dwell threshold was reached, the object briefly flashed and an auditory confirmation sound was played. If the captured object matched the target's color and shape, the round was marked as correct and the task advanced to the next round. If the captured object did not match the target, the system displayed wrong-object feedback, logged the event, and the participant continued searching in the same round.

At the beginning of each round, a fixation cross was shown between the two bookshelf columns. The upcoming target was displayed with the fixation cross and was also announced by the voice assistant. After the transition interval, the fixation cross disappeared, a brief randomized blank pause occurred, and the objects for the round appeared on the shelves. The same transition structure was used before the first round and between all subsequent rounds. This ensured that target information was presented during a controlled fixation phase rather than during active search.

Each active search round continued until the participant selected the correct target. Participants were free to take as much time as needed and were instructed to find the target as quickly and accurately as possible. The task therefore produced both performance outcomes, such as completion time and wrong selections, and gaze-behavior outcomes, such as fixation time on the target, fixation time on distractors, and search coverage across the shelf.

## Study Design

The study used a repeated-measures design in which all participants experienced both assistant conditions during a single run. The manipulated factor was assistant awareness, with two levels: gaze-unaware and gaze-aware. In gaze-unaware rounds, the assistant provided generic encouragement and pacing support without using the participant's gaze behavior. In gaze-aware rounds, the assistant used real-time gaze evidence to provide proximity-style feedback indicating whether the participant appeared to be off-target, on-track, or very close to the target. The gaze-aware assistant did not provide direct target-location hints such as shelf number, side, row, or exact object position.

Each participant completed 14 rounds. The condition schedule alternated by round: odd-numbered participant-facing rounds were gaze-unaware and even-numbered participant-facing rounds were gaze-aware. Thus, each participant completed seven gaze-unaware rounds and seven gaze-aware rounds. The target sequence and object compositions were generated from a deterministic challenge set using a fixed random seed. As a result, all participants experienced the same target order, distractor categories, and object combinations. The spatial shelf layout was generated once at the start of the run from the detected table and then reused across all rounds.

The primary independent variable was therefore assistant awareness. Round number was treated as a repeated within-participant variable to account for practice, fatigue, or strategy changes over time. Target identity, target shelf position, and distractor composition were controlled by the deterministic challenge set. Because the task alternated conditions every round, the design allowed gaze-aware and gaze-unaware assistance to be compared within the same participant while preserving the same apparatus, selection method, object set, and physical environment.

## Measures

Performance - Task performance was measured at the round and session levels. The primary performance measure was time to find the target, computed as the duration between the start of a round and the correct gaze-dwell capture. Accuracy was measured using the number of wrong captures before the correct capture and whether the target was captured on the first attempt. The system also recorded the total number of objectives completed, total completion time, and first-try accuracy across the run. Because each round continued until the target was found, completion time and wrong captures served as the main performance-sensitive dependent variables rather than binary success alone.

Gaze behavior - Gaze behavior was recorded continuously during active search. For each round, the system measured fixation time on the target, fixation time on distractors, fixation count on the target, fixation count on distractors, average fixation duration, saccade count, saccade frequency, and average saccade amplitude. Per-frame logs also recorded gaze origin, gaze direction, gaze rotation, fixation point when available, current hovered object, object shape and color, shelf level, target-match status, and dwell progress. These measures allowed the analysis to test whether gaze-aware assistance changed how participants searched, not only whether they found targets faster.

Assistant and event behavior - The trial event log recorded objective starts, fixation starts, fixation ends, correct captures, wrong captures, game completion, and post-run survey prompts. Each event was timestamped relative to the session and associated with the current objective, selected object, shelf metadata, and target-match status when applicable. These event logs made it possible to measure time from hint to selection, error patterns following wrong captures, and differences in gaze behavior between gaze-aware and gaze-unaware rounds.

Workload - Participants' perceived workload was measured after the run using the NASA-TLX questionnaire. The in-headset survey collected six 0 to 100 ratings: mental demand, physical demand, temporal demand, performance, effort, and frustration. These workload ratings were stored with the participant ID and run condition label for later analysis.

Physiological and eye-state measures - When available from the headset and OpenXR input stack, the system recorded left-eye and right-eye positions, eye openness values, fixation point, blink events, and cumulative blink count. Blink detection used smoothed bilateral eye-closure thresholds and duration constraints to reduce false positives from tracking noise or asymmetric squints. These measures were treated as exploratory indicators of visual state and task demand.

Subjective experience - The current implementation records NASA-TLX inside the headset. If the study includes a post-session questionnaire or interview, subjective experience measures should include perceived helpfulness of the assistant, perceived accuracy of the hints, trust in the assistant, annoyance, preference between conditions, and whether the participant noticed that some rounds used gaze-aware feedback. These measures would support interpretation of performance and workload differences, especially if gaze-aware hints improve search efficiency but increase perceived surveillance or distraction.

## Research Question and Hypotheses

This study aimed to answer the following research question: How does gaze-contingent assistant feedback affect performance, visual search behavior, and workload in a mixed reality object-finding task? Downstream of this, we were interested in understanding whether a gaze-aware assistant changes how participants allocate attention across target and distractor objects, and whether proximity-style spoken feedback can improve search without directly revealing the target location.

The following hypotheses were developed:

H1: Participants will find targets faster in gaze-aware rounds than in gaze-unaware rounds.

H2: Participants will make fewer wrong captures in gaze-aware rounds than in gaze-unaware rounds.

H3: Gaze-aware rounds will produce more efficient gaze behavior, reflected by a lower proportion of fixation time on distractors, fewer repeated fixations on non-target objects, and shorter time between first target fixation and correct capture.

H4: Participants' performance will improve over rounds as they become familiar with the shelf layout, gaze-dwell selection mechanic, and object set.

H5: Gaze-aware assistance will reduce perceived workload relative to gaze-unaware assistance if participants experience the feedback as useful, but may increase workload if the feedback is perceived as distracting or intrusive.

It was expected that gaze-aware feedback would improve performance because the assistant could respond to the participant's current search state rather than speaking on a purely generic basis. In particular, warmer-colder feedback was expected to help participants redirect attention when they were searching in an incorrect region and sustain attention when they were near the target. However, because gaze-aware hints were intentionally constrained to avoid direct target-location disclosure, the benefit was expected to appear primarily in reduced search inefficiency and fewer wrong selections rather than in an immediate elimination of visual search. The workload hypothesis was treated as partly directional and partly exploratory: gaze-contingent feedback could reduce mental demand by helping participants search more effectively, but it could also increase annoyance or perceived monitoring if participants found the assistant too reactive.

## Participants

Participants should be adults with normal or corrected-to-normal vision and no known condition that would prevent safe use of an immersive headset. Because the task relies on eye tracking and color-shape discrimination, participants should be screened for ability to perceive the stimulus colors and for compatibility with the headset's eye-tracking calibration. Participants should also be able to remain seated or standing at a table for the duration of the experiment and should have sufficient neck mobility to inspect all rows of the virtual bookshelf.

The final manuscript should report the actual number of recruited participants, exclusions, age range, gender distribution, vision correction status, prior XR experience, and any eye-tracking calibration failures. If participants are excluded due to unusable gaze data, inability to complete calibration, simulator discomfort, or incomplete runs, those exclusions should be reported before analysis.

## Procedure

Upon arrival, participants were greeted by the experimenter and completed the informed-consent process. They then completed any demographic and screening questions required by the study protocol, including prior experience with VR or AR, vision correction status, and color-vision concerns if applicable. The experimenter explained that the participant would complete a mixed reality visual-search task in which they would find a sequence of target objects by color and shape. Participants were told that objects would be selected by sustained gaze dwell rather than by grabbing them with a controller.

After the headset was fitted, the eye-tracking system was calibrated according to the headset procedure. The experimenter then positioned the participant in front of the physical table and started the mixed reality application. The participant viewed the passthrough environment and tapped the table surface to start the session. The system detected the table plane, generated the virtual bookshelf layout, and displayed the first fixation cross and target instruction. The voice assistant introduced the task and announced each round's target during the fixation phase.

Participants then completed the 14-round search task. On each round, the participant viewed the target instruction, waited for the fixation cross and blank pause to end, and searched the shelves for the target object. They selected an object by dwelling on it with their gaze. Correct selections advanced the task to the next round. Incorrect selections produced wrong-object feedback, after which the same round continued. The assistant provided either gaze-unaware or gaze-aware spoken hints depending on the current round condition. Participants were not required to know which condition was active on a given round.

After the final target was found, the application displayed a completion screen and prompted participants to complete the NASA-TLX workload questionnaire. The participant entered ratings for mental demand, physical demand, temporal demand, performance, effort, and frustration using the in-headset interface. After survey submission, the system showed a completion message and saved the run logs. Participants then removed the headset and, if included in the protocol, completed a short debriefing interview about assistant helpfulness, hint clarity, trust, annoyance, and preference between the different types of feedback.

The expected duration of the procedure depends on calibration time, participant search speed, and any post-session interview. A typical session should include headset fitting and calibration, task instructions, one complete 14-round run, NASA-TLX completion, and debriefing.
