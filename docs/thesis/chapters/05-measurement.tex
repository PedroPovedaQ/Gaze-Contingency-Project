\chapter{MEASURING VOICE OUTCOMES AND INTERACTION EXPOSURE}
\label{ch:measurement}
The research question becomes three measurement questions: did the participant perceive the voice as self-similar, did the voice condition change search performance, and how was the assistance experienced? Answering them requires both outcome measures and an account of exposure. This chapter connects voice identity, delivered speech, search events, and questionnaire responses so that recognizing the clone is not confused with benefiting from it. Detailed gaze and timing records support the interpretation, while Appendix~\ref{app:instruments} retains instrument wording and scoring.

\section{From Interaction Events to Research Variables}
The recorded data serve two purposes: reconstructing what happened in a trial and estimating the study outcomes. Reconstruction requires observations and events at their original temporal resolution, whereas statistical analysis usually requires a more compact table. The project therefore keeps trial summaries separate from gaze, head/controller motion, object layouts, and event streams, treating each summary as a derived representation rather than a replacement for the underlying evidence.

Every derived value needs an identifiable source and a definition. A number called ``time to gaze'' is ambiguous unless it specifies the clock origin, the contact rule, validity handling, and the treatment of missing observations. The same is true of an angle: wall assignment, gaze error, starting geometry, and accumulated rotation can all be expressed in degrees, but describe different quantities. The data contract preserves these meanings in separate fields.

Figure~\ref{fig:data-provenance} shows why a compact trial CSV must retain links to the underlying observations. Statistical scope and reconstruction detail impose different requirements on the exported data.

\section{Coordinate Frames and Starting Geometry}
Let $\mathbf{o}$ denote the saved trial reference origin, $\mathbf{c}$ the readiness-cross center, and $\mathbf{p}$ the target center. All three positions must be expressed in the same world coordinate frame. Let $\Pi(\mathbf{v})=(v_x,0,v_z)$ project a vector onto the horizontal plane. Define
\begin{equation}
\mathbf{a}=\Pi(\mathbf{c}-\mathbf{o}),\qquad
\mathbf{b}=\Pi(\mathbf{p}-\mathbf{o}).
\end{equation}
For nondegenerate vectors, the exact pre-cue starting angle is
\begin{equation}
\theta_0=\operatorname{atan2}\!\left(\hat{\mathbf{y}}\cdot(\mathbf{a}\times\mathbf{b}),\,\mathbf{a}\cdot\mathbf{b}\right)\frac{180}{\pi}.
\end{equation}
The sign convention will be verified against Unity's world-up signed-angle convention using known left and right targets. The absolute value $|\theta_0|$ describes horizontal demand from the saved cross reference. Exactly backward targets require a documented tie convention, because $-180$ and $+180$ identify the same horizontal bearing, although the absolute magnitude remains 180 degrees in either case.

This calculation is a required addition to the frozen study data contract. The October 20, 2026 implementation alignment audit (source register in Appendix~\ref{app:readiness}) found that existing signed and absolute theta fields represented nominal wall geometry relative to the previous target wall. They must not be renamed or silently interpreted as exact pre-cue measurements. A new snapshot must save origin, cross, target, timestamp, frame, and coordinate-frame identifier before the opening cue. If a horizontal vector is degenerate, the angle is unavailable; substituting zero would falsely describe an easy starting configuration.

Nominal categories remain useful for allocation: each block contains eight scheduled trials in each absolute category, $0,45,90,135,180$ degrees. Because an object can be positioned away from the center of its assigned wall, however, its exact bearing need not equal the nominal category, and balance across categories therefore does not prove exact geometric matching between voice blocks. Both assigned and realized geometry will be inspected.

The signed height difference is
\begin{equation}
\Delta h=p_y-c_y.
\end{equation}
Positive values identify targets above the cross center and negative values identify targets below it; this reference is not interchangeable with seated eye height. The planned 20-above/20-below allocation must be checked against realized positions and a prespecified near-zero rule, because at the source snapshot, floor-to-height scattering did not enforce that balance.

The three-dimensional distance measure relies on a different observation: the first valid tracked head position $\mathbf{h}_k$ after reveal. Its value is $d=\|\mathbf{p}-\mathbf{h}_k\|_2$, in metres, and the timestamp of $\mathbf{h}_k$ must accompany the distance. Because this post-reveal measurement describes geometry at an observed head pose, it cannot recover an unrecorded pre-cue snapshot.

Their purpose is to show why nominal wall assignment, exact cross-relative bearing, cross-relative height, and live gaze error require separate names and saved references.

\section{Trial Clocks and Pause Intervals}
Let $t_r$ be object reveal, $t_s$ correct selection, and $\mathcal{P}$ the union of valid pause intervals. Active completion time is
\begin{equation}
T_{\mathrm{active}}=(t_s-t_r)-\mu\!\left([t_r,t_s]\cap\mathcal{P}\right),
\end{equation}
where $\mu$ denotes elapsed duration. Using the union prevents overlapping pause reasons from being subtracted twice. For example, an application-focus pause can overlap a researcher-requested pause. The resulting active interval should remain stopped until all relevant pause reasons are resolved.

Readiness and opening speech precede reveal and are excluded from active search. This is an intentional outcome boundary, not missing task time. The system will nonetheless retain a broader opening-cue-to-selection interval so that analyses can describe the time spent receiving the initial instruction; because prepared clips can have different durations across voices, this additional record remains useful even though active completion is the primary outcome.

A stopped or timed-out trial has an observed duration and an outcome reason, but it does not have a successful completion time, and the analysis must not copy its stop timestamp into a success field. Similarly, a late-arriving file in the viewer reflects a transfer delay, not necessarily a delay in the headset event, which is why source timestamps and receive timestamps are kept distinct.

Recent conversational AR research illustrates why this definition should be stated explicitly. Madritsch et al. distinguish overall task-completion time from active working time in an assistant-supported procedural task~\cite{madritsch2026assistance}; the present clock is not assumed to correspond to theirs. In Follow My Voice, active completion time includes ordinary waits for guidance between object reveal and correct selection, and only recorded pauses are excluded. Separate decision and playback timestamps will therefore help explain delivery delays without removing their task-level consequences from the primary outcome.

\section{Gaze Contact, Vicinity, Pointing, and Selection}
Four event families are central to interpretation: a valid eye ray can intersect the target collider; a gaze direction can satisfy the larger target-vicinity rule; the right-controller ray can intersect the target; and a trigger press can select the target. These events can occur at different times and need not occur in that order in every recorded sample sequence.

The first gaze-contact latency uses the first valid recorded target-ray intersection after reveal. The last gaze-contact time uses the last such intersection before trial end. Neither is a fixation duration. If no contact is observed because of a blink, acquisition gap, or a path that only enters the broader vicinity, the contact field remains missing. The presence of a spoken acknowledgment does not justify filling in an unobserved ray contact.

Vicinity qualification is an interaction rule. In the documented system, a target can be acknowledged after 100 ms of valid qualifying evidence, with overlapping regions resolved to a single closest candidate. The rule trades exact collider intersection for a tolerance intended to make feedback usable, so that tolerance must be logged and piloted. The study-release tolerance remains to be frozen, and the default ring in the synthetic viewer screenshot is not a validated study setting. A very large region can produce premature acknowledgment even when its timing is correct.

Controller pointing is a distinct input observation, but its spoken acknowledgment is not independent of gaze, because the admission rule also requires valid nearby gaze. The documented pointing acknowledgment requires a qualified one-second controller hold with valid gaze in the target vicinity when speech is admitted. Before the hold completes, a valid target hit already suppresses contradictory away-directions; this suppression prevents a direction such as ``go back down'' from being delivered while the controller is already on the target, without falsely saying the hold has qualified. Correct trigger selection is the only event that successfully completes the search; a stop or timeout has a different outcome.

\section{Acquisition Rate, Validity, and Gaps}
A render loop can query an eye-tracking API frequently without receiving a new hardware observation each time, so the effective acquisition rate must be estimated from distinct source observations. If $n$ unique observations span source times $t_1$ through $t_n$, a basic rate summary is $(n-1)/(t_n-t_1)$. Because a mean alone can conceal bursty delivery, the distribution of successive intervals, repeated timestamps, invalid observations, and long gaps must accompany that average.

Application timestamps describe when data were handled, whereas source timestamps describe when the tracking observation was produced, if the API exposes them reliably. A clock-domain mapping must therefore be established before age or latency is computed across these clocks. If unique source timing is unavailable, the report will state that limitation rather than infer 120-Hz binocular delivery from polling or headset specifications.

Spatial validation will compare gaze direction with known independent targets. Angular error will be computed from normalized gaze and expected target directions, with invalid observations excluded from the error distribution but retained in availability summaries. Precision and bias should be considered separately, since a stable offset and a noisy signal can produce different guidance failures even when their average angular error is similar. The validation procedure must also describe target exposure, head pose, corrective lenses, and headset adjustments.

\section{Motion, Coverage, and Instructions}
Gross translation will sum Euclidean differences between adjacent valid head positions, and gross rotation will sum shortest quaternion angular differences; invalid intervals, excessive gaps, and pauses break the accumulation. Gross movement is a total, not a rate. If a separate movement-rate outcome is derived, its denominator will be observed covered time rather than the entire nominal session, because otherwise two runs with different data loss could produce misleadingly different movement rates.

Fixed-axis components derived from rotation vectors are not Euler yaw, pitch, and roll, and their labels will retain the actual calculation. Head motion also does not directly measure swivel-chair rotation, because the head can move relative to the torso and chair. Likewise, the seated avatar drawn at the scene center in Trial Review is a visualization convention, not evidence that measured head translation was zero.

Instruction counts will use actual software playback starts; a requested cue, a rejected model answer, and a prefetched clip are not delivered instructions. Opening cues, search guidance, acknowledgments, reminders, and success speech will have separate categories. The planned total of delivered active-search assistance includes directional guidance, gaze/pointing acknowledgments, and selection reminders, with each category also reported separately, while opening and success speech remain outside that total. Interrupted speech counts as started speech but retains its completion status, so it should not be treated as if the participant heard every word.

\section{Sequence-Level Latency}
For a qualified event, let $t_q$ denote the earliest supported qualification time and $t_p$ the actual software playback start of the corresponding acknowledgment. The primary engineering delay is
\begin{equation}
L_{\mathrm{software}}=t_p-t_q.
\end{equation}
This is not acoustic latency at the participant's ear, because audio-device buffering and the physical sound path require a separate measurement. Gaze and controller qualification times must also use their own definitions, since comparing a controller acknowledgment against first gaze contact would inflate or misattribute its delay.

Repeated requests about one continuously qualified event form a single episode, so a sequence can contain several Jev waits without creating several independent missed confirmations. An episode ends with playback, disqualification, trial termination, or a defined reset, and the evaluation will report how those endpoints were assigned, marking incomplete evidence as unknown.

Where logs support attribution, waiting will be divided into model response, explicit model deferral, scheduling, existing speech, and audio readiness. These intervals may overlap. They should not be added mechanically unless represented as a nonoverlapping partition of the critical path. The full event timeline remains the authority when aggregate attribution is ambiguous.

\section{Questionnaire Joins and Versioning}
Final questionnaire administration is separate from the block to which a response refers. A response collected after both blocks will therefore retain both its final-administration timing and a Block 1 or Block 2 reference, and the actual voice identifier must be joined through the saved order rather than inferred from block number. Practice is excluded from measured block outcomes even though it uses the first voice.

A convenience export may repeat a block-level workload score on every trial row. That does not create 40 independent workload observations. The analytical dataset will identify participant-by-block scope and collapse duplicate joins when estimating questionnaire effects. Raw responses, score direction, scale bounds, item identifiers, instrument version, and missingness will remain available.

The current NASA-TLX adaptation uses 0--10 ratings, whereas older development exports used 0--100, so automatic scoring must require explicit range metadata. A separately named normalized score can support comparison, but raw values must remain unchanged, and unknown legacy performance anchors cannot be repaired by guessing their direction. Complete-subscale rules for IMI and agent-perception measures will likewise be implemented and tested before confirmatory analysis.
