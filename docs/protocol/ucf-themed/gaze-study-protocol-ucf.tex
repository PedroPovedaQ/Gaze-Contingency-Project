\section{Read before rehearsal}
\begin{ucfcallout}{Current review findings | September 20, 2026}
\begin{itemize}
\item \textbf{Voice wording:} The run sheet's claim that wording varies by voice is outdated. The code now supports a shared Collaborative or External perspective locked for the session. The final study script still needs selection and headset validation.
\item \textbf{Questionnaire route:} The run sheet describes an in-headset NASA-TLX gate; the Qualtrics draft also contains TLX. Select and validate one collection route before collection.
\item \textbf{Response linkage:} The current post-session survey lacks a study-code field. Ensure participant and run identifiers are captured consistently across all forms.
\item \textbf{Open decisions:} Final repetitions, practice criteria, calibration thresholds, timeout and questionnaire selection remain unresolved.
\end{itemize}
\end{ucfcallout}
\section{Session at a glance}
\begin{tabularx}{\linewidth}{@{}p{0.8in}X@{}}

\textbf{Set up} & Consent, baseline questionnaire, headset fit/calibration and voice preparation. \\[10pt]
\textbf{Practice} & Center at the fixed front; rehearse gaze selection and pause procedures. \\[10pt]
\textbf{Block 1} & Search trials, block-specific measures and a headset-off break. \\[10pt]
\textbf{Block 2} & Revalidate fit/tracking/front; repeat the same procedure with the second voice. \\[10pt]
\textbf{Finish} & Final symptoms, preference/interview, debrief and data checks. \\
\end{tabularx}
