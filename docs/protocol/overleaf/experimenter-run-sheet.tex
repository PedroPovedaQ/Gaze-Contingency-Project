\say{SAY}{``First, I will explain the task. Your task is simply to locate objects that are around you. The objects that you'll need to find are specified by an agent. You will then continue this for other objects the agent specifies.}
\say{SAY}{``Next, read the displayed passage so the agent understands the way you speak".}
\meeting{OPEN QUESTION FROM MEETING}{Can we cover this in the consent step?}
