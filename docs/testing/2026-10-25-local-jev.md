# Local Jev action-policy experiment — 2026-10-25

**Implemented experiment; not deployed.** A locally fine-tuned action classifier reduced median request latency from 247.9 ms to 19.3 ms (12.85×; 92.2% lower), but matched only 7 of 10 expected production-case decisions. This model should not replace the study adviser. The deterministic authored-rule baseline matched all 10 cases and was considerably faster still.

## Model and data

Fine-tuned all 22,715,141 parameters of [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2), a pretrained encoder, with a five-class action head. Base revision: `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`. Saved weights occupy 90,872,572 bytes (90.9 MB). This is not Jev's proprietary model and does not generate speech or arbitrary text.

The 1,200 balanced training examples and 240 validation examples are synthetic, labeled from the app's authored action policy. Phrases come from `DirectionalHintPolicy`; an independent test compiles its actual C# `AllPhrases()` and checks generated text membership. Synthetic states assume local phrase eligibility and are not complete engine-generated trajectories. Input includes the policy's three-second silence band. No participant data, voice samples, gaze recordings or provider answer labels were used to train.

A 320-case held-out set contains unseen diagonal direction combinations and combined gate failures; it has no `orient` examples. Ten complete production-C# requests from the October 20 development pilot are a separate external holdout. Entire production cases were excluded from training and checkpoint selection. Expected actions were assigned from case definitions, independent of historical Jev answers. Repeated benchmark calls do not increase the number of independent quality cases.

Training used six fixed epochs, batch size 24, AdamW at 0.00004, fixed seeds and Mac MPS. It completed in 255 seconds including evaluation. Epoch 4 won validation selection (81.7%; epoch 5 tied, epoch 6 fell to 79.6%). The randomly initialized head scored 20.0% before training. Two preliminary runs were stopped before holdout evaluation to correct phrase provenance; their artifacts and reasons are preserved. No additional model was selected using the final test results.

## Decision agreement

These measure agreement with authored expected actions, not participant helpfulness or task performance.

| Dataset | Cases | Raw model | Offered-action mask | Mask plus mandatory gates |
|---|---:|---:|---:|---:|
| Validation | 240 | 81.7% | 81.7% | 91.3% |
| Unseen synthetic combinations | 320 | 65.0% | 68.4% | 77.8% |
| Production C# cases | 10 | 70.0% | 70.0% | 70.0% |

On the synthetic test, the raw model selected an unoffered action in 50 cases. After candidate masking it still selected speech in 30 cases with mandatory gate failures; external gates override those to `wait`. This protection is ordinary code, not learned competence. Missing recent-repeat suppression remains a quality failure even when the mandatory gates are open.

Production misses were `return_after_ack` (wait instead of correct), `recent_repeat` (orient instead of wait), and `left_stationary_inside` (wait instead of refine). Fresh Jev matched 8/10 unique cases, consistently across both repeats, missing the two corrective-return cases. Historical October 20 Jev results are retained separately; current results are not replaced with the more favorable historical scores.

## Latency

Same ten complete production payloads, two repetitions each, alternated local/cloud ordering. The local endpoint was warmed before measurement. The cloud first request is included. Both arms had 20/20 successful HTTP responses and zero transport/parse failures. The local model ran on MPS; each request includes tokenization, inference and HTTP serialization/transport. Jev includes the current Mac-to-cloud network cost.

| Request path | Median | p95 | Expected-action agreement |
|---|---:|---:|---:|
| Local model, loopback HTTP | 19.3 ms | 27.2 ms | 14/20 responses; 7/10 cases |
| Current Jev, cloud HTTP | 247.9 ms | 912.2 ms | 16/20 responses; 8/10 cases |

Separately, 100 direct local requests measured CPU median 30.0 ms / p95 54.6 ms and MPS median 20.3 ms / p95 29.4 ms. CPU load/first-request costs were 183/44 ms; MPS costs were 301/2,010 ms. A future service would need loading and warmup before a session.

The deterministic authored-rule reference measured median 0.0048 ms / p95 0.0050 ms over 1,000 **direct calls**, with 10/10 expected production-case decisions. This excludes HTTP and is not an apples-to-apples transport comparison with the table. Its perfect synthetic agreement would be tautological because it supplies training labels; its production-case agreement is the useful observation.

Small local development benchmark, no load soak or controlled isolation from other Mac processes. This measures no headset FPS, Wi-Fi routing, speech onset or participant outcomes. It does not establish a fix for the earlier audio-preparation frame stalls. Cloud latency varies; the stored October 20 comparison had median 179.5 ms / p95 246.0 ms.

## Decision and next evidence

**Open decision:** keep the study's current path unchanged. For the narrow action menu, a local deterministic policy is the stronger next candidate: it directly implements the desired behavior and avoids network latency. This experiment provides no quality reason to prefer the fine-tuned model over that baseline.

A learned replacement needs independently reviewed production-shaped sequence examples, including ordinary repeats, new corrective events, cue starvation, actual audio history and missing/noisy evidence. Split by whole session/scenario family, include all action classes in unseen tests, and compare against rules on examples the label oracle did not write. Evaluate in shadow mode before any participant-facing change. The current examples do not validate subjective helpfulness.

The prototype only supports `navigation_action`. Normal joint phrase/transmit choices, interruption decisions and round summaries remain unsupported. Any future adapter must retain Unity's final geometry, voice/condition identity, prepared-audio, cancellation and playback checks.
